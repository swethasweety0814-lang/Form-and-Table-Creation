# HTML Projects

This repository showcases basic HTML projects demonstrating fundamental web development concepts.

##  Projects Included

### 1. HTML Form
A simple form implementation with:
- Input fields (text, email, number, date)
- Radio buttons (gender selection)
- Checkboxes (course selection)
- Dropdown menu
- Textarea for user input
- Form validation using required attributes

### 2. HTML Table
A basic table structure displaying student data:
- Table headers and rows
- Proper use of <table>, <tr>, <th>, and <td> tags

##  Technologies Used
- HTML5
- css

##  Purpose
This project is created to practice and demonstrate core HTML concepts required for beginners in web development.

##  How to Run
1. Download or clone the repository
2. Open the `.html` files in any web browser
